# Book to Kindle

Cloudflare-first ebook delivery workflow for finding books and sending them to Kindle.

> Development agents: read [`AGENTS.md`](./AGENTS.md) before changing architecture or language-routing behavior. The core contract is **model understands natural language/context; deterministic code performs bibliographic lookup, workflow state and side effects**.

For the Telegram assistant architecture and regression contract, see [`docs/ASSISTANT_AGENT.md`](./docs/ASSISTANT_AGENT.md).

The rest of this project documentation remains in the files under [`docs/`](./docs/).
