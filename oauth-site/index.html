Book to Kindle

Book to Kindle is a personal utility that helps its user search for an ebook, choose a file, and send that selected file to the user's configured Kindle email address.

How Google data is used

The application requests only the Gmail permission required to send email (gmail.send). It uses that permission solely to send the user-selected ebook as an email attachment to the user's configured Kindle address.

The application does not read the user's inbox, messages, contacts, or other Gmail content.

Privacy

For details about how Google user data and OAuth credentials are handled, read the Privacy Policy.

Book to Kindle is an independent personal application and is not affiliated with or endorsed by Google or Amazon.
