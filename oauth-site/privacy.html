Privacy Policy

Effective date: September 6, 2026

This Privacy Policy explains how Book to Kindle accesses and uses Google user data.

Google data accessed

Book to Kindle requests only the Gmail scope https://www.googleapis.com/auth/gmail.send. This permission allows the application to send email on behalf of the authorized user.

How Google data is used

The Gmail permission is used only to send an ebook file selected by the user to the Kindle email address configured by that user. Book to Kindle does not use the Gmail API to read the user's inbox, messages, contacts, or other Gmail content.

Storage and security

OAuth credentials required for the service are stored as protected application secrets and are used only to obtain access tokens needed for the requested Gmail sending operation. Access tokens are not used for unrelated purposes.

Sharing of Google user data

Book to Kindle does not sell Google user data and does not share Google user data with advertisers or unrelated third parties. Data is transmitted to Google APIs only as necessary to provide the requested email-sending functionality.

Data retention

The application does not retain copies of the user's Gmail mailbox content because it does not read that content. Temporary ebook files used for delivery are handled separately from Google user data and are removed after the delivery workflow according to the application's operational policy.

Revoking access

The user may revoke Book to Kindle's Google Account access at any time through the Google Account third-party access controls. Revocation prevents future Gmail API access until authorization is granted again.

Changes to this policy

If the application's handling of Google user data changes, this policy will be updated before the changed practice is used.

Return to Book to Kindle

Book to Kindle is an independent personal application and is not affiliated with or endorsed by Google or Amazon.
